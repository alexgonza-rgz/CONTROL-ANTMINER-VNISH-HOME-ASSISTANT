# Seguridad

No publiques incidencias que contengan:

- La contraseña de VNish.
- Tokens devueltos por `/api/v1/unlock`.
- Credenciales o nombres privados de pools.
- Archivos HAR sin revisar y limpiar.

La integración está diseñada para utilizarse exclusivamente dentro de una red local de confianza. No abras los puertos HTTP o SSH del Antminer directamente a Internet.

Para informar de una vulnerabilidad, utiliza un canal privado del propietario del repositorio en lugar de una incidencia pública.
