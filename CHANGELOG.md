# Changelog

## 1.0.0 — 2026-08-20

- Monitorización completa mediante la API VNish.
- Corrección del conteo de placas usando `miner.chains[].status.state`.
- Control autenticado de minería, throttle y reinicios.
- Selección de 25 perfiles con potencia y hashrate estimado.
- Ajuste manual de frecuencia y voltaje.
- Configuración automática de ventiladores y lectura del duty actual.
- Protección térmica, watchdog y aviso de desconexión.
- Tarjeta Lovelace nativa, compacta y ordenada.
